# نظام إدارة صيانة الأجهزة الطبية (CMMS)

تطبيق MVP عربي من اليمين إلى اليسار لإدارة صيانة الأجهزة الطبية باستخدام Streamlit وSQLAlchemy وSQLite. استخدم بيانات وهمية فقط في العرض السحابي؛ هذا الإصدار ليس نظامًا سريريًا معتمدًا.

## التشغيل محليًا (Windows / Linux)

يتطلب Python 3.12 موصى به. من جذر المشروع:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
pip install -r requirements-dev.txt
python -m seed.seed_demo
streamlit run streamlit_app.py
```

لتشغيله على شبكة المستشفى المحلية فقط، شغّل `streamlit run streamlit_app.py --server.address 0.0.0.0 --server.port 8501` ثم قيّد المنفذ في جدار الحماية.

## الحسابات التجريبية

جميع كلمات المرور الأولية `ChangeMe123!`: `supervisor`, `engineer1`, `engineer2`, `nurse1`, `nurse2`, `nurse3`, `procurement`. لا تستخدمها في بيئة حقيقية.

## النشر من GitHub إلى Streamlit Community Cloud

1. ارفع محتويات هذا المجلد مباشرة إلى جذر المستودع، وليس المجلد الأب أو ملف ZIP.
2. في Streamlit Community Cloud اختر المستودع والفرع.
3. اجعل **Main file path** = `streamlit_app.py` واختر Python 3.12 إذا أتاحته إعدادات التطبيق.
4. من إعدادات التطبيق > Secrets، أضف `DEMO_MODE = "true"` لعرض المستثمر.
5. بعد النشر اختبر تسجيل الدخول بنفسك. بيانات SQLite في الاستضافة المجانية مؤقتة وقد تضيع عند إعادة التشغيل؛ لا تدخل بيانات مستشفى أو مرضى حقيقية.

قاعدة البيانات المحلية هي `data/cmms.db` ويمكن تحديد مسار آخر بمتغير البيئة `CMMS_DB_PATH`. في وضع العرض تستخدم قاعدة مؤقتة في مجلد النظام المؤقت. يقوم التطبيق بإنشاء الجداول وتعبئة بيانات العرض عند بدء التشغيل إذا لم توجد حسابات. يعتمد إصدار MVP على `Base.metadata.create_all()` ولا يتضمن بعد ترحيلات Alembic إنتاجية.

## النطاق والقيود

يتضمن الإصدار الحالي الدخول والأدوار، سجل الأجهزة، فحوصات التمريض، البلاغات وأوامر العمل، طلبات شراء أساسية، الإشعارات، ومؤشرات عامة وتصدير CSV. أُضيف مسار استئناف الإصلاح من حالة انتظار القطع. لم يتم التحقق من جميع مسارات الأدوار باستخدام AppTest أو من نشر سحابي حي؛ كما أن مهام العامل الخلفي الكاملة، لوحة التصعيد والامتثال التفصيلية، وخدمة دورة الشراء المكتملة واختبارات القبول الشاملة ما تزال بحاجة إلى استكمال قبل الاستخدام التشغيلي.
